## Motivation

Describe work once to Firstmate and follow its progress in Linear.

## How to do it

Talk to Firstmate as usual.
Describe the outcome, repository, and constraints:

> Add team invitations to the app.
> Invitations should expire after seven days and be usable only once.
> Prepare a plan for my approval before implementation.

**FM Linear tracks new work requests automatically.**
You do not need to create an issue yourself.
If an issue already exists, share its link so Firstmate can reuse it.
To keep a request out of Linear, say “Don't create a Linear issue for this request.”

## What happens

Firstmate shares the Linear issue link in your conversation.
The issue collects the request, plan, decisions, and deliverables as work progresses.

In the recommended workflow:

- Work waiting to start uses **ToDo**; planning uses **Plan In Progress**.
- A finished plan moves to **Approve Plan** for your [feedback](/guides/reviews/) or [approval](/guides/approve-plan/).
- Labels identify the crew; the assignee tells you who needs to act next.

## How it works

Firstmate records and organizes the work.
FM Linear reads those records, creates or links the Linear issue, and keeps later updates connected to it.
If Linear is unavailable, the update stays pending.
