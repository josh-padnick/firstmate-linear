**FM Linear is an independent community project.**
It is not affiliated with, endorsed by, or maintained by [Kun Chen (`kunchenguid`)](https://github.com/kunchenguid) or the [Firstmate project](https://github.com/kunchenguid/firstmate).
FM Linear's maintainers are responsible for the integration, its compatibility, and this documentation.

## What “plugin” means here

We call FM Linear a Firstmate plugin to describe what it does: add Linear-based tracking and communication to Firstmate.
The word does not mean it is an official Firstmate extension or an endorsed integration.

Firstmate offers limited extension capabilities, but it does not have a general-purpose plugin system that supports this entire integration as a first-class capability.
FM Linear uses a dedicated adapter to connect through available Firstmate interfaces without requiring an upstream fork.
Those interfaces have limits, and changes to Firstmate can affect compatibility.
See [the integration overview](/reference/architecture/) for the mechanisms and their limitations.

## Names and imagery

The Firstmate and Linear names and imagery identify the tools FM Linear connects.
Their appearance here does not imply sponsorship, endorsement, or official ownership of FM Linear.

## Where to get help

Bring setup questions, compatibility problems, and integration bugs to the [FM Linear repository](https://github.com/josh-padnick/fm-linear/issues).
FM Linear's maintainers should investigate integration issues before referring a confirmed upstream bug to another project.

Continue with [Set up FM Linear](/guides/setup/), or read [the integration overview](/reference/architecture/) to understand the connection.
